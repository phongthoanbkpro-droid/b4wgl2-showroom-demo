# Atelier One · Blend4Web CE native demo

A noncommercial demo built around an original geometric Blender scene authored for this project; it contains no cfchonmau3vn, MAUBOM, TH02 or customer assets. The scene is exported as `assets/atelier.json` and `assets/atelier.bin`; its editable source and generation script are in `source/`. It is a conceptual form, not a real product or specification. Mouse orbit and touch use Blend4Web's native camera controls; physical-phone behavior has not been certified.

`b4w.min.js` is the unmodified official Blend4Web CE 18.05 build from Triumph LLC's [18.05 release source, commit e589ac769d3405f32b1dddc62d6a325382fd950e](https://github.com/TriumphLLC/Blend4Web/tree/e589ac769d3405f32b1dddc62d6a325382fd950e). To regenerate the scene with Blender 2.79 and the compatible CE SDK, set `B4W_SDK_ROOT` and `BLENDER_USER_SCRIPTS` to the SDK root and run `blender -b --factory-startup --python source/build_scene.py`. Serve this directory over HTTP, e.g. `python -m http.server`, and open it in a WebGL-capable browser. All deployed scene and runtime URLs are relative to this directory. The source project uses geometry and solid materials only; no third-party textures or original customer scene assets.
